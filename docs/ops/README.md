号池的「健康与质量」运营面，与业务转发解耦：只观测、只建议，不参与热路径决策。

| 模块 | 文档 | 判什么 | 当前状态 |
|---|---|---|---|
| 门票（打票） | [ticketing.md](./ticketing.md) | 上游是否给我们铸回合门票、块数是否符合套餐 | 只读检测已上线 |
| 降智检测 | [iq-detection.md](./iq-detection.md) | 能力是否下降（题库 + 鹈鹕结构指纹） | 设计完成，待实现 |

## 设计原则

1. **只读优先**：先观测、留证据，再谈自动动作。
2. **分层判据**：不同模型 / effort / 套餐不跨层比较，避免误判。
3. **未采集不猜**：没有埋点的字段一律标「未采集」，不填 0、不估算。
4. **动作可回滚**：任何降权/停调度都要有 `auto_restore` 与明确原因码。
